Question 7:
Needs improvement.

A while loop does not specifically compare two values, and a for loop does not run until a condition is met.

A clearer distinction is:

- while: repeats while a condition remains True
- for: repeats once for each item in a sequence or range

A while loop is useful when the number of repetitions may not be known in advance.
A for loop is useful when iterating through known values or items.
